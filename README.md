# Eggora Fresh Eggs

Fresh egg delivery website, orange and marble design with WhatsApp ordering.

Live site: https://snegha032002.github.io/eggora/

## Edit
- Brand name, phone, email, WhatsApp number, prices: top of `js/main.js` (`SITE` and `PRODUCTS`).
- Photos: replace files in `images/` keeping the same names.
- Orders are sent on WhatsApp from `order.html`. Set your real number in `SITE.whatsapp`.

Plain HTML, CSS and JavaScript. No build step.
